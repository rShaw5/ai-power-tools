# QUICKSTART (about 20 minutes)

1. Read `README.md` above to see which example fits you (2 min).
2. Open `Example 1 - Generate a book study plan/` and skim
   `HOW-GENERATED.md` to see the workflow end to end (5 min).
3. Open `Example 2 - Set up Planning Mode/` and read `RATIONALE.md`,
   then skim the annotated thread in `examples/plan-session.md` to see
   how questions reshape a plan (8 min).
4. Open `Example 3 - Try career-ops/` and follow `SETUP.md` to run
   the public project yourself (5 min to start; the project itself
   takes longer).
