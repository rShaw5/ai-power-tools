# AI Power Tool Examples

Three small, practical examples of getting more out of an AI assistant:
plan before acting, study a book with help, and run a job-search workflow.
Each example stands alone — start with whichever sounds most useful.

## What's inside

- `Example 1 - Generate a book study plan/` — research a book, track reading notes, and queue follow-ups.
- `Example 2 - Set up Planning Mode/` — a planning template, the rationale behind it, and an annotated planning thread.
- `Example 3 - Try career-ops/` — pointers for running the public career-ops project.
- `QUICKSTART.md` — a 20-minute tour touching all three examples.

Everything here is a starting point to copy and adapt. Where this kit
describes someone else's project, it links to the public source; the
templates and worked examples are the kit's own.
