# Career-ops cold start 

Official project: https://github.com/career-ops-hq/career-ops

Career-ops is an open-source job search workflow: it scans job portals,
scores listings against your CV, tailors application materials, and tracks
applications — all on your own machine, in the coding assistant you already use.

1. Read the repo README and `docs/SETUP.md` there.
2. Run the one-command init from the README to create your project folder.
3. Run the repo's doctor check to validate prerequisites.
4. Copy the example profile and portals files as directed in the docs.
5. Open your assistant in that directory and follow the onboarding chat.

Full FAQ, budget, and automation guides live under `docs/` in that repo.
Nothing here replaces the official docs; this is just a starting pointer.
